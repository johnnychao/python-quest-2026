## 怎麼開始

1. 打開入口網頁，登錄你的暱稱。
2. 點任一關卡的「在 Colab 開啟」（需要 Google 帳號）。
3. 在筆記本最上方的「魔法工具箱」填入同樣的暱稱並執行。
4. 完成每個 🎯 任務後執行它下方的「檢查」格；全部 ✅ 後執行「通關密語」。
5. 把密語貼回入口網頁蓋章。

> 💾 建議在 Colab 選「檔案 → 在雲端硬碟中儲存副本」，你的進度才會留在自己的雲端硬碟。
